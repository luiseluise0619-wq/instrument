# SLYCE Companion 8마디 MIDI

각 파일은 4/4, 정확히 8마디이며 트랙 이름과 MIDI 텍스트 이벤트에 사용할
SLYCE 프리셋 이름이 들어 있습니다. DAW에서 트랙별로 SLYCE 인스턴스를 만든 뒤
표시된 프리셋을 선택하면 됩니다.

- `SLYCE_Velvet_8bar.mid`: Velvet Vocal Kit / Velvet EP / Velvet Bass / Human Air
- `SLYCE_Glass_8bar.mid`: Glass Vocal Kit / Crystal Drop / Pearl Bell / Pure Sub
- `SLYCE_Dream_8bar.mid`: Dream Vocal Kit / Midnight Keys / Cloud Pad / Soft Chime

이 파일은 외부 렌더 오디오가 아니라 실제 MIDI 연주 데이터입니다. 보컬 키트는
보컬 키트 모드, 나머지 세 트랙은 Instrument 모드에서 사용해야 합니다.
