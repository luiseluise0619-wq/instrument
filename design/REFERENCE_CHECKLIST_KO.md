# Reference UI 출시 전 실제 실행 점검

아래 항목은 체크리스트이며, 완료됐다고 표시한 검증 결과가 아니다.

- [ ] 실제 Windows/macOS/Linux 빌드 성공 및 새 실행파일 식별자 `REF-20260920-04` 확인
- [ ] Paper Light / Noir Violet 전환, 호스트 저장 후 테마 복원
- [ ] 100% / 125% / 150% / 200% DPI에서 글자·노브·마커·클릭 위치 대조
- [ ] 960×640, 1229×819, 1536×1024 화면 크기에서 팝업과 컨트롤 경계 검사
- [ ] 실제 JUCE 캡처와 제공된 레퍼런스의 패널 경계/재질 비교
- [ ] 노브 7개 + 피치/모드 휠의 파라미터 값, 자동화, 더블클릭 초기화
- [ ] 파형 확대/이동/수동 마커/그리드 마커/페이지별 패드 인덱스
- [ ] 키보드와 타이핑 키의 note on/off, 검색창 입력 시 음 발생 방지, 창 닫기 시 음 해제
- [ ] 음원/SFZ 로딩, 전체 악기/프리셋 탐색, 사용자 프리셋 저장/복원
- [ ] 루퍼 열기/닫기, Play/Stop, 길이 선택, 실제 오버더빙/Undo/Export
- [ ] 상세 ADSR/FX/Master/Modulation, 코드 바, 라이선스 창 접근 및 닫기
- [ ] DSP/음원 변경 없이 기존 프로젝트와 출력 비교

브라우저 미리보기에서는 오디오 처리와 네이티브 위젯/API 오류를 확인할 수 없다.
