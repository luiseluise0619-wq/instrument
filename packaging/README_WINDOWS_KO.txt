SLYCE Windows 설치 / 업데이트

1. FL Studio와 다른 DAW를 모두 종료합니다.
2. install-windows.bat을 실행합니다.
3. 관리자 권한 요청이 나타나면 허용합니다.
4. FL Studio에서 Options > Manage plugins > Find more plugins를 실행합니다.

업데이트 동작
- 새 Slyce.vst3를 먼저 복사하고 정상적인 Slyce 번들인지 확인합니다.
- 기존 Slyce 설치본은 VST3 폴더에서 제거한 뒤 새 버전으로 교체합니다.
- 구버전은 복구할 수 있도록 사용자 폴더의 Slyce-previous-version에 보관합니다.
- 플러그인 제조사 코드, 플러그인 코드, 제품명이 유지되므로 기존 프로젝트의
  Slyce 트랙은 업데이트 버전을 같은 악기로 인식합니다.
- 라이선스 티켓은 설치 폴더가 아닌 AppData의 Slyce 폴더에 저장되므로
  같은 Windows PC에서 업데이트할 때 다시 인증할 필요가 없습니다.

Standalone 실행파일은 Standalone 폴더의 Slyce.exe입니다.

사용자 샘플 불러오기
- SLYCE 왼쪽 USER 탭을 누릅니다.
- 맨 위 YOUR SAMPLE 영역을 누르고 WAV/AIFF/FLAC/OGG/MP3 파일 하나를 고릅니다.
- 또는 오디오 파일을 SLYCE 창 아무 곳에 끌어놓습니다.
- 한 샘플이 C3를 원음으로 사용해 건반 전체에 자동 매핑됩니다.
- 왼쪽 아래 LOAD / DROP YOUR SAMPLE 버튼도 같은 기능입니다.

이번 빌드의 주요 변경
- 사용자 제공 6곡을 보컬 스템으로 분리해 24개 뱅크/192개 가창 슬라이스로 교체했습니다.
- 이전 합성 보컬과 드럼·하이햇·입 퍼커션 소스는 출시 바이너리에서 제거했습니다.
- 비활성 구형 보컬 카탈로그와 합성 보컬 대체 코드도 소스에서 제거했습니다.
- MAIN 7개, FX 4개, MASTER 7개 노브와 주요 버튼의 실제 상태 변경을 자동 검사했습니다.
- 보컬 조각마다 킥 저역 제거, 반주 트랜지언트 중첩 검사, 클릭 방지 페이드와 체감 음량 정규화를 적용했습니다.
- 새 건반을 누르면 이전 보컬이 짧게 페이드되며 즉시 교체됩니다.
- 전체 샘플 미리듣기는 한 번 끝까지 재생됩니다.
- USER 탭에 사용자 샘플 진입점을 고정했습니다.
- Theme, Mapped Sample, Slices, Looper 등 화면 용어를 정리했습니다.
- 루퍼 MIDI CC20-34로 녹음/오버더빙/정지/트랙 전환을 제어할 수 있습니다.
- 현재 UI에서 사용하지 않는 구형 편집기 코드를 제거했습니다.
- Windows에서 깨지던 SAVE 상태 문자와 브라우저 범위 문자를 ASCII로 교체했습니다.
- 루퍼 1-6번의 Rec/Set/Dub/Play 버튼 폭을 늘려 글자가 잘리지 않게 했습니다.
- 주요 버튼과 모달 진입 경로를 실제 JUCE 클릭 콜백으로 전수 검사했습니다.
