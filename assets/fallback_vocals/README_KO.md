# 합성 보컬 대체 에셋

이 폴더의 80개 WAV는 누락된 원본 보컬을 복원한 파일이 아닙니다. 코드로 만든 합성 모음·코러스·숨결·타격성 텍스처입니다. 실제 사람 녹음이 없으므로 원본 목소리를 개선했다고 주장하지 않습니다.

각 파일은 4초 / 44,100 Hz / mono / PCM16입니다. 생성은 tools/generate_fallback_vocals.py, 파일 해시는 manifest.csv에 있습니다. 재생 결과의 음악적 취향 적합성은 청음으로 결정해야 합니다.

프로젝트 examples 폴더 또는 SLYCE_ORIGINAL_VOCALS_DIR에 같은 이름의 원본 WAV를 넣으면 CMake가 해당 원본을 우선합니다. 합성 파일을 쓸 때만 [SYN] 표기가 생성됩니다. 파일명이 기존 카탈로그를 따르더라도 특정 가수나 연령대의 실제 음성을 의미하지 않습니다.
