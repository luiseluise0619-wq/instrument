# Third-party / provenance notes

This bundle contains the user's supplied SLYCE source with modifications, test scaffolding, and newly generated procedural audio. It does not assign a new license to the user's pre-existing project. The original project owner's distribution choices still apply.

JUCE and Signalsmith dependencies are fetched or supplied separately. Their source/license files are not bundled here. Before distributing a built product, check the license terms accompanying the exact versions you actually use. SLYCE activation and the CMake demo switch do not grant JUCE distribution rights.

The 80 WAVs in assets/fallback_vocals were generated by tools/generate_fallback_vocals.py using oscillators, formant-like resonators, noise, envelopes and deterministic seeds. They are synthetic vowel/choir/percussion textures, not recovered human vocal recordings, samples purchased from third-party libraries, or imitations of an identified person. The manifest records the generated file bytes. The supplied reference PNGs belong to the conversation input and are reference design material, not screenshots of this build.

No fonts, external commercial sample banks, SDK binaries, signing certificates, or user activation secrets are bundled. Python scientific libraries are optional tooling dependencies and have their own terms; they are not needed at plugin runtime.
